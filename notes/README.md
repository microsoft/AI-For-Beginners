# 学习笔记系统

> 与 Claude 互动学习 AI-For-Beginners 课程的记录。
> 所有内容维护在 `my-learning-notes` 分支, 不影响主分支。

## 📁 目录结构

```
notes/
├── README.md        ← 你正在看的文件
├── progress.md      ← 学习进度 (按时间顺序, 每次学习追加一条)
├── mistakes/        ← 错题本 & 疑难问题
│   ├── README.md
│   └── *.md         ← 每道错题 / 难题一个文件
└── keynotes/        ← 重点笔记 (按课程章节组织)
    ├── README.md
    └── *.md         ← 每节课一个文件, 命名格式: <编号>-<slug>.md
```

## 🎯 三类记录说明

### 1. `progress.md` — 学习进度
记录"我今天学了哪些内容、花了多久、掌握度如何"。**只追加, 不修改**。

### 2. `mistakes/` — 错题 & 疑难
做题/做实验时**答错、理解错、卡住**的地方。每条独立成文, 方便后续反复回看。
文件命名: `<日期>-<主题简述>.md`, 例如 `2026-08-11-perceptron-step-function.md`

### 3. `keynotes/` — 重点笔记
每节课的**核心概念、易考点、易混点**。按课程章节对齐, 命名格式: `<lesson编号>-<slug>.md`
例如 `03-perceptron.md`、`07-ConvNets.md`

## 🔄 日常使用流程

| 步骤 | 操作 | 命令 |
|------|------|------|
| 1 | 在 Claude 里学习某个章节 | — |
| 2 | 让我帮你在 `progress.md` 追加一条 | — |
| 3 | 让我把重点写到 `keynotes/<lesson>.md` | — |
| 4 | 把错题写到 `mistakes/<date>-<topic>.md` | — |
| 5 | 提交并推送 | `git add . && git commit -m "..." && git push` |

## 💡 提示
- 三类记录**分别面向不同需求**: 进度给"自己回看节奏", 错题给"反复巩固", 笔记给"考前速览"。
- 让我帮你写时, 直接说"帮我加一条进度" / "这道题加入错题本" / "写一下第3课的重点" 即可。
- 所有笔记都在 `notes/` 下, 不会污染课程原文。
