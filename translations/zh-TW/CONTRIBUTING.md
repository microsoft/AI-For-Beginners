# 為 AI-初學者 貢獻

感謝您對 AI-初學者 的貢獻興趣！我們歡迎翻譯、課程修正以及格式校正。

## 微軟貢獻者許可協議 (CLA)

本專案歡迎貢獻與建議。大多數貢獻需您同意一份貢獻者許可協議 (CLA)，聲明您有權利且確實授權我們使用您的貢獻。詳情請見 [https://cla.microsoft.com](https://cla.microsoft.com)。

當您提交拉取請求時，CLA機器人會自動判斷您是否需要提供CLA，並適當標註該PR（如標籤、評論）。僅需依機器人指示操作一次即可，適用於所有使用我們CLA的儲存庫。

## 如何貢獻

### 1. 修正錯字 / 代碼錯誤
如果您發現任何 Jupyter 筆記本或課程 markdown 文件中的錯字或錯誤：
1. 分叉該儲存庫。
2. 修正錯字或錯誤連結。
3. 提交拉取請求並清楚描述修正內容。

### 2. 提交翻譯
我們歡迎課程翻譯成其他語言！請將翻譯置於 `translations/` 目錄下，依照現有的資料夾名稱 (例如 `translations/es/`、`translations/pt-BR/`、`translations/zh-CN/`)。

詳情請參見 [etc/CONTRIBUTING.md](etc/CONTRIBUTING.md)。
