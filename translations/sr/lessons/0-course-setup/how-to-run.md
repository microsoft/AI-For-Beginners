# Како покренути код

Овај наставни план садржи много извршних примера и лабораторијских вежби које желите да покренете. Да бисте то урадили, потребна вам је могућност извршавања Python кода у Jupyter Notebook-овима који су обезбеђени као део овог наставног плана. Имали сте неколико опција за покретање кода:

## Покрени локално на свом рачунару

Да бисте покренули код локално на свом рачунару, потребна је инсталација Python-а. Једна препорука је да инсталирате **[miniconda](https://conda.io/en/latest/miniconda.html)** - то је прилично лагана инсталација која подржава `conda` менаџер пакета за различита Python **виртуелна окружења**.

Након што инсталирате miniconda, клонирајте репозиторијум и направите виртуелно окружење које ће се користити за овај курс:

```bash
git clone http://github.com/microsoft/ai-for-beginners
cd ai-for-beginners
conda env create --name ai4beg --file .devcontainer/environment.yml
conda activate ai4beg
```

> **Напомена за Windows**: Ако прављење окружења не успе приликом инсталирања `gdk-pixbuf` са `UnicodeDecodeError` која спомиње `gbk` кодек, укључите UTF-8 режим у Python-у у вашем терминалу и покушајте поново. Користите синтаксу за терминал који користите:
>
> **PowerShell:**
>
> ```powershell
> $env:PYTHONUTF8 = "1"
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Command Prompt (`cmd.exe`) или Anaconda Prompt:**
>
> ```cmd
> set PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Bash, укључујући Git Bash:**
>
> ```bash
> export PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> Ако неуспели покушај остави `ai4beg` окружење, деактивирајте га и уклоните пре поновног покушаја. Прво користите `conda deactivate` када је окружење активно:
>
> ```text
> conda deactivate
> conda env remove --name ai4beg
> ```

### Коришћење Visual Studio Code са Python екстензијом

Овај наставни план се најбоље користи ако се отвори у [Visual Studio Code](http://code.visualstudio.com/?WT.mc_id=academic-77998-cacaste) са [Python Extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python&WT.mc_id=academic-77998-cacaste).

> **Напомена**: Када клонирате и отворите директоријум у VS Code, аутоматски ће вам бити понуђено да инсталирате Python екстензије. Такође ћете морати да инсталирате miniconda као што је описано горе.

> **Напомена**: Ако вам VS Code предложи да поново отворите репозиторијум у контејнеру, требало би да одбијете ову опцију како бисте користили локалну Python инсталацију.

### Коришћење Jupyter-а у прегледачу

Можете користити и Jupyter окружење из прегледача на свом рачунару. И класични Jupyter и JupyterHub пружају погодно окружење за развој са аутоматским допуњавањем, истакнућем кода итд.

Да покренете Jupyter локално, идите у директоријум курса и извршите:

```bash
jupyter notebook
```
или
```bash
jupyterhub
```
Затим можете да приступите било којој `.ipynb` датотеци, отворите је и почнете са радом.

### Покретање у контејнеру

Једна алтернатива инсталацији Python-а је покретање кода у контејнеру. Пошто наш репозиторијум обезбеђује посебан `.devcontainer` фајл који показује како се гради контејнер за овај репо, VS Code вам нуди могућност поновног отварања кода у контејнеру. Ово ће захтевати инсталацију Dockera и такође ће бити сложеније, па ову опцију препоручујемо искуснијим корисницима.

## Покретање у облаку

Ако не желите да инсталирате Python локално и имате приступ неким ресурсима у облаку - добра алтернатива је да покренете код у облаку. Постоји неколико начина да то урадите:

* Коришћење **[GitHub Codespaces](https://github.com/features/codespaces)**, што је виртуелно окружење које вам GitHub креира, доступно преко VS Code интерфејса у прегледачу. Ако имате приступ Codespaces, само кликните на дугме **Code** у репозиторијуму, покрените codespace и одмах започните рад.
* Коришћење **[Binder](https://mybinder.org/v2/gh/microsoft/ai-for-beginners/HEAD)**. [Binder](https://mybinder.org) нуди бесплатне рачунарске ресурсе у облаку како бисте тестирали неки код на GitHub-у. На почетној страни постоји дугме да отворите репозиторијум у Binder-у - ово ће вас брзо одвести до сајта биндера, који ће изградити контејнер у позадини и покренути Jupyter веб интерфејс.

> **Напомена**: Да би спречио злоупотребе, Binder има блокиран приступ неким веб ресурсима. То може спречити рад дела кода који преузима моделе и/или скупове података са јавног интернета. Можда ћете морати да пронађете нека заобилазна решења. Такође, рачунарски ресурси које пружа Binder су прилично основни, па ће тренинг на каснијим, сложенијим лекцијама бити спор.

## Покретање у облаку са GPU-ом

Неке од каснијих лекција у овом наставном плану ће много имати користи од подршке за GPU. Тренинг модела, на пример, може бити веома спор у супротном. Постоји неколико опција које можете следити, посебно ако имате приступ облаку кроз [Azure for Students](https://azure.microsoft.com/free/students/?WT.mc_id=academic-77998-cacaste) или кроз вашу институцију:

* Креирајте [Data Science Virtual Machine](https://docs.microsoft.com/learn/modules/intro-to-azure-data-science-virtual-machine/?WT.mc_id=academic-77998-cacaste) и повежите се на њу преко Jupyter-а. Онда можете клонирати репо директно на машину и започети учење. NC-серија виртуелних машина има подршку за GPU.

> **Напомена**: Неки планови, укључујући Azure for Students, не обезбеђују подршку за GPU одмах. Можда ћете морати да затражите додатне GPU језгре преко техничке подршке.

* Креирајте [Azure Machine Learning Workspace](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-cacaste) и онда користите Notebook функцију тамо. [Овај видео](https://azure-for-academics.github.io/quickstart/azureml-papers/) показује како да клонирате репозиторијум у Azure ML notebook и почнете да га користите.

Такође можете користити Google Colab, који пружа нешто бесплатне подршке за GPU, и тамо отпремити Jupyter Notebook-ове да их извршавате један по један.
