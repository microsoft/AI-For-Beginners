## Mitä opit

**[Kurssin miellekartta](http://soshnikov.com/courses/ai-for-beginners/mindmap.html)**

Tässä oppimateriaalissa opit:

* Erilaisia tekoälyn lähestymistapoja, mukaan lukien "hyvä vanha" symbolinen lähestymistapa **Tietämyksen esittämisen** ja päättelyn avulla ([GOFAI](https://en.wikipedia.org/wiki/Symbolic_artificial_intelligence)).
* **Neuroverkot** ja **Syväoppiminen**, jotka ovat nykyaikaisen tekoälyn ydin. Havainnollistamme näitä tärkeitä aiheita koodin avulla kahdessa suosituimmassa kehikossa - [TensorFlow](http://Tensorflow.org) ja [PyTorch](http://pytorch.org).
* **Neuroarkkitehtuurit** kuvien ja tekstin käsittelyyn. Käsittelemme uusimpia malleja, mutta emme välttämättä ole täysin ajan tasalla viimeisimmistä kehityksistä.
* Vähemmän suosittuja tekoälyn lähestymistapoja, kuten **Geneettisiä algoritmeja** ja **Moniagenttijärjestelmiä**.

Mitä emme käsittele tässä oppimateriaalissa:

> [Löydä kaikki lisäresurssit tälle kurssille Microsoft Learn -kokoelmastamme](https://learn.microsoft.com/en-us/collections/7w28iy2xrqzdj0?WT.mc_id=academic-77998-bethanycheum)

* Liiketoiminnan tapauksia **tekoälyn käytöstä liiketoiminnassa**. Suosittelemme [Tekoälyn perusteet liiketoiminnalle](https://docs.microsoft.com/learn/paths/introduction-ai-for-business-users/?WT.mc_id=academic-77998-bethanycheum) -oppipolkua Microsoft Learnissa tai [AI Business School](https://www.microsoft.com/ai/ai-business-school/?WT.mc_id=academic-77998-bethanycheum), joka on kehitetty yhteistyössä [INSEADin](https://www.insead.edu/) kanssa.
* **Perinteistä koneoppimista**, joka on hyvin kuvattu meidän [Koneoppiminen aloittelijoille -kursseissamme](http://github.com/Microsoft/ML-for-Beginners).
* Käytännön tekoälysovelluksia, jotka on rakennettu käyttäen **[Cognitive Services](https://azure.microsoft.com/services/cognitive-services/?WT.mc_id=academic-77998-bethanycheum)**. Tähän suosittelemme Microsoft Learnin moduuleja [näkökyvystä](https://docs.microsoft.com/learn/paths/create-computer-vision-solutions-azure-cognitive-services/?WT.mc_id=academic-77998-bethanycheum), [luonnollisen kielen käsittelystä](https://docs.microsoft.com/learn/paths/explore-natural-language-processing/?WT.mc_id=academic-77998-bethanycheum), **[Generatiivisesta tekoälystä Azure OpenAI -palvelulla](https://learn.microsoft.com/en-us/training/paths/develop-ai-solutions-azure-openai/?WT.mc_id=academic-77998-bethanycheum)** ja muista.
* Erityisiä ML:n **pilvikehityskehyksiä**, kuten [Azure Machine Learning](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-bethanycheum), [Microsoft Fabric](https://learn.microsoft.com/en-us/training/paths/get-started-fabric/?WT.mc_id=academic-77998-bethanycheum) tai [Azure Databricks](https://docs.microsoft.com/learn/paths/data-engineer-azure-databricks?WT.mc_id=academic-77998-bethanycheum). Suosittelemme oppipolkuja [Build and operate machine learning solutions with Azure Machine Learning](https://docs.microsoft.com/learn/paths/build-ai-solutions-with-azure-ml-service/?WT.mc_id=academic-77998-bethanycheum) ja [Build and Operate Machine Learning Solutions with Azure Databricks](https://docs.microsoft.com/learn/paths/build-operate-machine-learning-solutions-azure-databricks/?WT.mc_id=academic-77998-bethanycheum).
* **Keskusteleva tekoäly** ja **Chatbotit**. Tälle on oma [Create conversational AI solutions](https://docs.microsoft.com/learn/paths/create-conversational-ai-solutions/?WT.mc_id=academic-77998-bethanycheum) oppipolkunsa, ja voit myös katsoa [tämän blogikirjoituksen](https://soshnikov.com/azure/hello-bot-conversational-ai-on-microsoft-platform/) lisätietoja varten.
* **Syvällinen matematiikka** syväoppimisen takana. Tätä varten suosittelemme teosta [Deep Learning](https://www.amazon.com/Deep-Learning-Adaptive-Computation-Machine/dp/0262035618) kirjoittajilta Ian Goodfellow, Yoshua Bengio ja Aaron Courville, joka on myös saatavilla verkossa osoitteessa [https://www.deeplearningbook.org/](https://www.deeplearningbook.org/).

Lempeään johdantoon _AI pilvessä_ -aiheisiin voit harkita [Get started with artificial intelligence on Azure](https://docs.microsoft.com/learn/paths/get-started-with-artificial-intelligence-on-azure/?WT.mc_id=academic-77998-bethanycheum) -oppimispolun suorittamista.

> **Huomio kyselyistä**: Kaikki kyselyt löytyvät Quiz-app-kansiosta polussa etc\quiz-app, tai [verkkossa täällä](https://ff-quizzes.netlify.app/). Ne ovat linkitetty oppitunneilta, kyselysovellus voidaan suorittaa paikallisesti tai ottaa käyttöön Azureen; noudata ohjeita `quiz-app`-kansiossa. Niitä lokalisoidaan vähitellen.
