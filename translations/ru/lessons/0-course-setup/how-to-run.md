# Как запустить код

В этой учебной программе много выполняемых примеров и лабораторных работ, которые вы захотите запустить. Для этого вам понадобится возможность выполнять Python-код в Jupyter Notebook, предоставленных в рамках этого курса. У вас есть несколько вариантов запуска кода:

## Запуск локально на вашем компьютере

Чтобы запускать код локально на вашем компьютере, необходимо установить Python. Одним из рекомендуемых вариантов является установка **[miniconda](https://conda.io/en/latest/miniconda.html)** — это достаточно легкая установка, которая поддерживает пакетный менеджер `conda` для различных **виртуальных сред** Python.

После установки miniconda склонируйте репозиторий и создайте виртуальную среду, которая будет использоваться для этого курса:

```bash
git clone http://github.com/microsoft/ai-for-beginners
cd ai-for-beginners
conda env create --name ai4beg --file .devcontainer/environment.yml
conda activate ai4beg
```

> **Примечание для Windows**: Если создание среды завершается неудачей при установке `gdk-pixbuf` с `UnicodeDecodeError`, в которой упоминается кодек `gbk`, включите режим UTF-8 в Python в вашем терминале и попробуйте снова. Используйте синтаксис для вашего терминала:
>
> **PowerShell:**
>
> ```powershell
> $env:PYTHONUTF8 = "1"
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Командная строка (`cmd.exe`) или Anaconda Prompt:**
>
> ```cmd
> set PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Bash, включая Git Bash:**
>
> ```bash
> export PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> Если предыдущая неудачная попытка оставила среду `ai4beg`, деактивируйте её и удалите перед повторной попыткой. Сначала используйте `conda deactivate`, когда среда активна:
>
> ```text
> conda deactivate
> conda env remove --name ai4beg
> ```

### Использование Visual Studio Code с расширением Python

Для работы с этой учебной программой рекомендуется использовать [Visual Studio Code](http://code.visualstudio.com/?WT.mc_id=academic-77998-cacaste) с [расширением Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python&WT.mc_id=academic-77998-cacaste).

> **Примечание**: После клонирования и открытия папки в VS Code вам автоматически будет предложено установить расширения для Python. Также необходимо будет установить miniconda, как описано выше.

> **Примечание**: Если VS Code предлагает вам заново открыть репозиторий в контейнере, следует отказаться от этого, чтобы использовать локальную установку Python.

### Использование Jupyter в браузере

Вы также можете использовать Jupyter-среду из браузера на вашем собственном компьютере. Классический Jupyter и JupyterHub предоставляют удобную среду разработки с автодополнением, подсветкой кода и т.д.

Чтобы запустить Jupyter локально, перейдите в каталог курса и выполните:

```bash
jupyter notebook
```
или
```bash
jupyterhub
```
Вы затем можете открыть любой из `.ipynb` файлов и начать работу.

### Запуск в контейнере

Альтернативой установке Python может быть запуск кода в контейнере. Поскольку в нашем репозитории есть специальная папка `.devcontainer` с инструкциями по сборке контейнера для этого репозитория, VS Code предоставляет возможность заново открыть код в контейнере. Для этого потребуется установка Docker, и это будет более сложно, поэтому мы рекомендуем этот вариант более опытным пользователям.

## Запуск в облаке

Если вы не хотите устанавливать Python локально и у вас есть доступ к облачным ресурсам, хорошей альтернативой станет запуск кода в облаке. Существуют несколько способов сделать это:

* Использование **[GitHub Codespaces](https://github.com/features/codespaces)** — виртуальной среды, созданной для вас на GitHub и доступной через браузерный интерфейс VS Code. Если у вас есть доступ к Codespaces, просто нажмите кнопку **Code** в репозитории, запустите codespace и начните работу в считанные минуты.
* Использование **[Binder](https://mybinder.org/v2/gh/microsoft/ai-for-beginners/HEAD)**. [Binder](https://mybinder.org) предоставляет бесплатные вычислительные ресурсы в облаке, чтобы вы могли тестировать код на GitHub. На главной странице репозитория есть кнопка для открытия репозитория в Binder — это быстро перенаправит вас на сайт Binder, который соберет контейнер и запустит веб-интерфейс Jupyter для вас.

> **Примечание**: Чтобы предотвратить злоупотребления, доступ Binder к некоторым веб-ресурсам заблокирован. Это может помешать работе части кода, который скачивает модели и/или наборы данных с публичного Интернета. Возможно, вам придется искать обходные пути. Также вычислительные ресурсы Binder достаточно базовые, поэтому обучение будет медленным, особенно на более поздних, сложных уроках.

## Запуск в облаке с поддержкой GPU

Некоторые более поздние уроки этого курса существенно выигрывают от поддержки GPU. Тренировка моделей, например, без этого может идти очень медленно. Есть несколько вариантов, которые вы можете использовать, особенно если у вас есть доступ к облаку через [Azure для студентов](https://azure.microsoft.com/free/students/?WT.mc_id=academic-77998-cacaste) или через вашу организацию:

* Создайте [виртуальную машину для Data Science](https://docs.microsoft.com/learn/modules/intro-to-azure-data-science-virtual-machine/?WT.mc_id=academic-77998-cacaste) и подключитесь к ней через Jupyter. Вы сможете клонировать репозиторий прямо на эту машину и начать обучение. Виртуальные машины серии NC поддерживают GPU.

> **Примечание**: Некоторые подписки, включая Azure для студентов, по умолчанию не включают поддержку GPU. Возможно, вам придется запросить дополнительные GPU-ядра через техническую поддержку.

* Создайте [рабочее пространство Azure Machine Learning](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-cacaste) и используйте там функцию Notebook. [Это видео](https://azure-for-academics.github.io/quickstart/azureml-papers/) показывает, как клонировать репозиторий в Azure ML notebook и начать использовать его.

Также вы можете использовать Google Colab, который предоставляет бесплатную поддержку GPU, и загружать туда Jupyter Notebook для последовательного выполнения.
