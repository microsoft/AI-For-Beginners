# نحوه اجرای کد

این برنامه درسی شامل تعداد زیادی مثال‌ها و آزمایش‌های قابل اجرا است که ممکن است بخواهید آنها را اجرا کنید. برای انجام این کار، باید توانایی اجرای کد پایتون را در دفترچه‌های Jupyter که به عنوان بخشی از این برنامه درسی ارائه شده‌اند، داشته باشید. چندین گزینه برای اجرای کد دارید:

## اجرا به صورت محلی روی رایانه خودتان

برای اجرای کد به صورت محلی روی کامپیوترتان، نیاز به نصب پایتون دارید. یک پیشنهاد این است که **[miniconda](https://conda.io/en/latest/miniconda.html)** را نصب کنید - این یک نصب سبک است که از مدیر بسته `conda` برای محیط‌های **مجازی پایتون** مختلف پشتیبانی می‌کند.

پس از نصب miniconda، مخزن را کلون کرده و یک محیط مجازی برای استفاده در این دوره ایجاد کنید:

```bash
git clone http://github.com/microsoft/ai-for-beginners
cd ai-for-beginners
conda env create --name ai4beg --file .devcontainer/environment.yml
conda activate ai4beg
```

> **نکته ویندوز**: اگر هنگام ایجاد محیط در حین نصب `gdk-pixbuf` خطایی همراه با `UnicodeDecodeError` که به کدک `gbk` اشاره دارد دریافت کردید، حالت UTF-8 پایتون را در ترمینال خود فعال کرده و دوباره امتحان کنید. از دستوری که مربوط به ترمینال مورد استفاده شماست استفاده کنید:
>
> **PowerShell:**
>
> ```powershell
> $env:PYTHONUTF8 = "1"
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Command Prompt (`cmd.exe`) یا Anaconda Prompt:**
>
> ```cmd
> set PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Bash، از جمله Git Bash:**
>
> ```bash
> export PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> اگر تلاش ناموفقی محیط `ai4beg` را باقی گذاشت، آن را غیرفعال کرده و حذف کنید، سپس دوباره تلاش کنید. ابتدا هنگام فعال بودن محیط از `conda deactivate` استفاده کنید:
>
> ```text
> conda deactivate
> conda env remove --name ai4beg
> ```

### استفاده از Visual Studio Code با افزونه Python

بهترین راه استفاده از این برنامه زمانی است که آن را در [Visual Studio Code](http://code.visualstudio.com/?WT.mc_id=academic-77998-cacaste) با [Python Extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python&WT.mc_id=academic-77998-cacaste) باز کنید.

> **توجه**: پس از کلون کردن و باز کردن پوشه در VS Code، به طور خودکار به شما پیشنهاد نصب افزونه‌های پایتون داده می‌شود. همچنین باید miniconda را طبق توضیحات بالا نصب کنید.

> **توجه**: اگر VS Code به شما پیشنهاد باز کردن مجدد مخزن در یک کانتینر داد، برای استفاده از نصب محلی پایتون این پیشنهاد را رد کنید.

### استفاده از Jupyter در مرورگر

همچنین می‌توانید از محیط Jupyter از طریق مرورگر روی کامپیوتر خود استفاده کنید. هر دو Jupyter کلاسیک و JupyterHub یک محیط توسعه راحت با تکمیل خودکار، برجسته‌سازی کد و غیره ارائه می‌دهند.

برای شروع Jupyter به صورت محلی، به پوشه دوره رفته و اجرا کنید:

```bash
jupyter notebook
```
یا
```bash
jupyterhub
```
سپس می‌توانید به هر یک از فایل‌های `.ipynb` مراجعه کرده، آنها را باز کرده و شروع به کار کنید.

### اجرای کد در کانتینر

یک گزینه جایگزین برای نصب پایتون، اجرای کد در کانتینر است. از آنجایی که مخزن ما پوشه مخصوص `.devcontainer` را فراهم می‌کند که به شما نحوه ساخت کانتینر برای این مخزن را می‌آموزد، VS Code امکان باز کردن مجدد کد در کانتینر را فراهم می‌کند. این نیاز به نصب Docker دارد و کمی پیچیده‌تر است، بنابراین توصیه می‌کنیم این روش را کاربران با تجربه تر استفاده کنند.

## اجرای کد در فضای ابری

اگر نمی‌خواهید پایتون را به صورت محلی نصب کنید و به منابع ابری دسترسی دارید، راه جایگزین خوبی اجرای کد در فضای ابری است. چندین روش برای انجام این کار وجود دارد:

* استفاده از **[GitHub Codespaces](https://github.com/features/codespaces)**، که محیط مجازی ساخته شده برای شما بر روی GitHub است و از طریق رابط VS Code در مرورگر قابل دسترسی است. اگر به Codespaces دسترسی دارید، می‌توانید فقط دکمه **Code** را در مخزن بزنید، کدسپیس را شروع کنید و به سرعت کد اجرا شود.
* استفاده از **[Binder](https://mybinder.org/v2/gh/microsoft/ai-for-beginners/HEAD)**. [Binder](https://mybinder.org) منابع رایگان رایانشی که به صورت ابری ارائه می‌دهد را برای افرادی مانند شما فراهم می‌کند تا کدهای GitHub را تست کنند. دکمه‌ای در صفحه اول وجود دارد که مخزن را در Binder باز می‌کند - این شما را سریع به سایت Binder می‌برد که یک کانتینر پایه می‌سازد و یک رابط وب Jupyter را بدون دردسر شروع می‌کند.

> **توجه**: برای جلوگیری از سوء استفاده، دسترسی Binder به برخی منابع وب محدود شده است. این ممکن است باعث شود برخی کدها که مدل‌ها و/یا مجموعه داده‌ها را از اینترنت عمومی می‌گیرند کار نکنند. شاید نیاز به راه‌حل‌های جایگزین داشته باشید. همچنین منابع محاسباتی ارائه شده توسط Binder پایه‌ای هستند، بنابراین آموزش ممکن است کند باشد، به خصوص در درس‌های بعدی که پیچیده‌تر هستند.

## اجرای کد در فضای ابری با GPU

برخی از درس‌های پیشرفته‌تر این دوره از پشتیبانی GPU بهره زیادی می‌برند. برای مثال آموزش مدل ممکن است در غیر این صورت به شدت کند باشد. چند گزینه دارید، خصوصاً اگر از طریق [Azure for Students](https://azure.microsoft.com/free/students/?WT.mc_id=academic-77998-cacaste) یا از طریق موسسه خود به فضای ابری دسترسی دارید:

* ایجاد [Data Science Virtual Machine](https://docs.microsoft.com/learn/modules/intro-to-azure-data-science-virtual-machine/?WT.mc_id=academic-77998-cacaste) و اتصال به آن از طریق Jupyter. سپس می‌توانید مخزن را مستقیماً روی ماشین کلون کرده و شروع به یادگیری کنید. ماشین‌های NC-series از GPU پشتیبانی می‌کنند.

> **توجه**: برخی اشتراک‌ها، از جمله Azure for Students، به طور پیش‌فرض پشتیبانی از GPU ارائه نمی‌دهند. ممکن است نیاز باشد با درخواست پشتیبانی فنی، هسته‌های GPU اضافی درخواست کنید.

* ایجاد [Azure Machine Learning Workspace](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-cacaste) و سپس استفاده از قابلیت Notebook آنجا. [این ویدیو](https://azure-for-academics.github.io/quickstart/azureml-papers/) نشان می‌دهد چگونه یک مخزن را در نوت‌بوک Azure ML کلون کرده و شروع به استفاده کنید.

همچنین می‌توانید از Google Colab استفاده کنید، که همراه با پشتیبانی رایگان GPU است، و نوت‌بوک‌های Jupyter را آنجا آپلود کرده و یکی‌یکی اجرا کنید.
