# Contributing

Yeh project contributions aur suggestions ka swagat karta hai. Zyaadatar contributions ke liye aapko ek Contributor License Agreement (CLA) se agree karna hoga, jisme aap declare karte hain ki aapke paas rights hain aur aap hume apne contribution ko use karne ka right dete hain. Details ke liye, https://cla.microsoft.com par jaaiye.

Jab aap ek pull request submit karte hain, toh CLA-bot automatically determine karega ki aapko CLA provide karne ki zaroorat hai ya nahi aur PR ko appropriately decorate karega (jaise, label, comment). Bas bot ke diye gaye instructions follow kijiye. Aapko yeh sirf ek baar karna hoga un sabhi repositories mein jo hamara CLA use karti hain.

Is project ne [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) ko adopt kiya hai. Zyada information ke liye [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) dekhiye ya kisi bhi additional questions ya comments ke liye [opencode@microsoft.com](mailto:opencode@microsoft.com) par contact kijiye.
