# Lessons ka translation karke contribute karein

Hum is curriculum ke lessons ke translations ka swagat karte hain!

## Guidelines

Har lesson folder aur lesson introduction folder mein translated markdown files hoti hain.

> Dhyaan dein, please code sample files mein koi bhi code translate na karein; sirf README, assignments aur quizzes ko translate karein. Dhanyavaad!

Translated files ko is naming convention ka paalan karna chahiye:

**README._[language]_.md**

jahaan _[language]_ ek do-letter language abbreviation hai jo ISO 639-1 standard follow karta hai (jaise Spanish ke liye `README.es.md` aur Dutch ke liye `README.nl.md`).

**assignment._[language]_.md**

README ki tarah, please assignments ko bhi translate karein.

**Quizzes**

1. Apna translated quiz yahaan add karein: https://github.com/microsoft/AI-For-Beginners/tree/main/etc/quiz-app/src/assets/translations, sahi naming convention ke saath (jaise en.json, fr.json). **Please 'true' ya 'false' words ko localize na karein. Dhanyavaad!**

2. Quiz-app ki App.vue file mein dropdown mein apna language code add karein.

3. Quiz-app ki [translations index.js file](https://github.com/microsoft/AI-For-Beginners/blob/main/etc/quiz-app/src/assets/translations/index.js) edit karein aur apni language add karein.

4. Aakhir mein, apni translated README.md files mein saare quiz links edit karein taaki woh seedhe aapke translated quiz ki taraf point karein: https://red-field-0a6ddfd03.1.azurestaticapps.net/quiz/1 ko badal kar https://red-field-0a6ddfd03.1.azurestaticapps.net/quiz/1?loc=id kar dein.

**Dhanyavaad**

Hum aapki koshishon ki sach mein kadar karte hain!
