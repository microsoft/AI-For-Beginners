# Ek Ontology Banaiye

Knowledge base banana kisi topic ke facts ko represent karne wale model ko classify karne ke baare mein hai. Ek topic chuniye - jaise koi person, place, ya object - aur phir us topic ka ek model banaiye. Is lesson mein bataye gaye kuch techniques aur model-building strategies use kijiye. Ek example yeh ho sakta hai ki aap ek living room ki ontology banayein jisme furniture, lights, aadi shamil hon. Living room kitchen se kaise alag hai? Bathroom se? Aapko kaise pata chalta hai ki yeh living room hai aur dining room nahi? Apni ontology banane ke liye [Protégé](https://protege.stanford.edu/) use kijiye.
