# Teachers ke liye

Kya aap is curriculum ko apni classroom mein use karna chahenge? Please, bejhijhak use kijiye!

Asal mein, aap ise GitHub ke andar hi GitHub Classroom use karke implement kar sakte hain.

Iske liye, is repository ko fork karein. Aapko har lesson ke liye ek alag repository banani hogi, isliye aapko har folder ko alag-alag repository mein extract karna hoga. Is tarah, [GitHub Classroom](https://classroom.github.com/classrooms) har lesson ko alag-alag pehchan sakega.

Yeh [complete instructions](https://github.blog/2020-03-18-set-up-your-digital-classroom-with-github-classroom/) aapko samjhane mein madad karenge ki apni classroom ko kaise set up karein.

## Repository ko current form mein use karna

Agar aap is repository ko uske current form mein use karna chahte hain, GitHub Classroom use kiye bina, toh yeh bhi possible hai. Aapko apne students ko batana hoga ki kaunsa lesson saath mein complete karna hai.

Online format (Zoom, Teams, ya koi aur) mein, aap quizzes ke liye breakout rooms bana sakte hain aur students ko seekhne ke liye taiyaar karne mein madad kar sakte hain. Phir students ko quizzes ke liye invite karein aur unse kaho ki ek tay waqt par apne answers 'issues' ke roop mein submit karein. Agar aap chahte hain ki students open mein collaboratively kaam karein, toh aap assignments ke saath bhi aisa kar sakte hain.

Agar aap zyada private format pasand karte hain, toh apne students se kahein ki woh curriculum ko lesson-by-lesson apni khud ki GitHub repositories mein fork karein, jo private repositories hon, aur aapko access dein. Phir woh quizzes aur assignments ko privately complete kar sakte hain aur unhe aapki classroom repository par issues ke through submit kar sakte hain.

Online classroom format mein ise kaam mein lane ke kai tareeke hain. Please humein batayein ki aapke liye sabse accha kya kaam karta hai!

## Please humein apne vichaar batayein

Hum chahte hain ki yeh curriculum aapke aur aapke students ke liye useful ho. Please discussion board mein humein apna feedback dein!
