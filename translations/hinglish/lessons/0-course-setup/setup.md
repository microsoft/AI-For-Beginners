## Kya aap Student hain?

Neeche diye gaye resources ke saath shuru karein:

* [Student Hub Page](https://docs.microsoft.com/learn/student-hub?WT.mc_id=academic-77998-cacaste) Is page par aapko beginner resources, Student Packs, aur free certificate voucher paane ke tareeke bhi milenge. **Students**, is curriculum ko use karne ke kuch tareeke hain. Sabse pehle, aap seedha GitHub par text padh sakte hain aur code dekh sakte hain. Agar aap kisi bhi notebook mein code run karna chahte hain - [hamare instructions padhein](./how-to-run.md), aur yeh kaise karna hai uske baare mein aur salah [is blog post mein](https://soshnikov.com/education/how-to-execute-notebooks-from-github/) paayein.

## Self-study

Lekin agar aap is curriculum ko self-study project ki tarah lena chahte hain, toh hum suggest karte hain ki aap poori repo ko apne GitHub account mein fork kar lein aur exercises ko khud ya group ke saath complete karein:

* Pre-lecture quiz se shuru karein.
* Lecture ka introductory text padhein.
* Agar lecture mein extra notebooks hain, toh unhein padhein aur code run karein. Agar TensorFlow aur PyTorch dono notebooks diye gaye hain, toh aap kisi ek par focus kar sakte hain - apna favourite framework chuniye.
* Notebooks mein aksar kuch challenges hote hain jinmein aapko code ko thoda badalna aur experiment karna padta hai.
* Post-lecture quiz lein.
* Agar module ke saath koi lab juda hai - assignment complete karein.
* [Discussion Board](https://github.com/microsoft/AI-For-Beginners/discussions) par jaayein aur "learn out loud" karein.

> Aage ki padhai ke liye, hum in [Microsoft Learn](https://docs.microsoft.com/en-us/users/dmitrysoshnikov-9132/collections/31zgizg2p418yo/?WT.mc_id=academic-77998-cacaste) modules aur learning paths ko follow karne ki salah dete hain.

**Teachers**, hamne is curriculum ko use karne ke liye [kuch suggestions shaamil kiye hain](./for-teachers.md).

## Pedagogy

Is curriculum ko banate waqt hamne do pedagogical principles chune hain: yeh ensure karna ki yeh **project-based** ho aur isme **frequent quizzes** shaamil hon.

Jab content projects ke saath align hota hai, toh process students ke liye zyada engaging ban jaata hai aur concepts ki understanding badhti hai. Saath hi, class se pehle ka ek low-stakes quiz student ko topic seekhne ke intent ki taraf le jaata hai, jabki class ke baad ka doosra quiz aage ki retention pakki karta hai. Yeh curriculum flexible aur fun banaya gaya hai aur ise poora ya aanshik roop se liya ja sakta hai. Projects chhote se shuru hote hain aur 12-week cycle ke ant tak dheere-dheere complex ho jaate hain.

> **Quizzes ke baare mein ek note**: Saare quizzes [is app](https://red-field-0a6ddfd03.1.azurestaticapps.net/) mein hain, jisme total 50 quizzes hain, har ek mein teen questions. Yeh lessons ke andar se link kiye gaye hain, lekin quiz app ko locally bhi run kiya ja sakta hai; `etc/quiz-app` folder mein diye gaye instructions follow karein.

## Offline Access

Aap is documentation ko offline [Docsify](https://docsify.js.org/#/) ka use karke run kar sakte hain. Is repo ko fork karein, apni local machine par [Docsify install karein](https://docsify.js.org/#/quickstart), aur phir is repo ke root folder mein `docsify serve` type karein. Website aapke localhost par port 3000 par serve hogi: `localhost:3000`. Curriculum ka ek PDF [is link par available hai](../../../../../../../../../etc/pdf/readme.pdf).
