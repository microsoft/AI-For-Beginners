# RNN use karke Word-Level Text Generation

[AI for Beginners Curriculum](https://github.com/microsoft/ai-for-beginners) ka lab assignment.

## Task

Is lab mein, aapko koi bhi book leni hai aur use dataset ke roop mein use karke ek word-level text generator train karna hai.

## Dataset

Aap koi bhi book use kar sakte hain. [Project Gutenberg](https://www.gutenberg.org/) par aapko bahut saari free books mil sakti hain. Jaise, yahaan Lewis Carroll ki [Alice's Adventures in Wonderland](https://www.gutenberg.org/files/11/11-0.txt) ka direct link hai.
