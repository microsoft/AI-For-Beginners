# PyTorch/TensorFlow ke saath Classification

[AI for Beginners Curriculum](https://github.com/microsoft/ai-for-beginners) se Lab Assignment.

## Task

PyTorch ya TensorFlow use karke do classification problems solve karein, jisme single aur multi-layered fully-connected networks shamil hain:

1. **[Iris classification](https://en.wikipedia.org/wiki/Iris_flower_data_set)** problem - yeh ek aisa example hai jisme tabular input data hota hai, jise traditional machine learning se handle kiya ja sakta hai. Aapka goal 4 numerical parameters ke basis par irises ko 3 classes mein classify karna hoga.
1. **MNIST** handwritten digit classification problem, jise hum pehle dekh chuke hain.

Best accuracy paane ke liye alag-alag network architectures try karein.
