# MNIST Classification Apne Khud ke Framework ke saath

[AI for Beginners Curriculum](https://github.com/microsoft/ai-for-beginners) se lab assignment.

## Task

1-, 2- aur 3-layer wale perceptrons use karke MNIST handwritten digit classification ki problem solve kijiye. Us neural network framework ko use kijiye jo humne lesson mein develop kiya hai.

## Starting Notebook

Lab shuru karne ke liye [MyFW_MNIST.ipynb](../../../../../../lessons/3-NeuralNetworks/04-OwnFramework/lab/MyFW_MNIST.ipynb) kholiye.

## Questions

Is lab ke result ke roop mein, neeche diye gaye questions ke answers dene ki koshish kijiye:

- Kya inter-layer activation function network ki performance ko affect karta hai?
- Kya is task ke liye 2- ya 3-layer wala network zaroori hai?
- Kya aapko network train karte waqt koi problem aayi? Khaas taur par jab layers ki sankhya badhi.
- Training ke dauran network ke weights kaise behave karte hain? Aap weights ki maximum value (max abs value) ko epoch ke saath plot karke is relationship ko samajh sakte hain.
