# Game Jam

Games ek aisa field hai jo AI aur ML ke development se bahut gehraai se prabhavit hua hai. Is assignment mein, ek aise game par chhota article likhiye jo aapko pasand ho aur jo AI ke development se prabhavit hua ho. Yeh game itna purana hona chahiye ki use kai tarah ke computer processing systems se prabhavit hone ka mauka mila ho. Ek accha example Chess ya Go ho sakta hai, lekin video games jaise Pong ya Pac-Man ko bhi dekhiye. Ek aisa essay likhiye jo game ke past, present aur AI ke future par charcha kare.
