# Optical Flow se Movement Detect karna

[AI for Beginners Curriculum](https://aka.ms/ai-beginners) se lab assignment.

## Task

[Is video](../../../../../../lessons/4-ComputerVision/06-IntroCV/lab/palm-movement.mp4) ko dekhiye, jisme ek insaan ka haath static background par left/right/up/down ki taraf move karta hai.

**Aapka goal** yeh hoga ki optical flow ka use karke pata lagayein ki video ke kaun se hisse mein up/down/left/right movement hai.

**Stretch goal** yeh hoga ki aap skin color ka use karke haath/finger ki movement ko actually track karein, jaise [is blog post](https://dev.to/amarlearning/finger-detection-and-tracking-using-opencv-and-python-586m) ya [yahan](http://www.benmeline.com/finger-tracking-with-opencv-and-python/) bataya gaya hai.

## Starter Notebook

Lab shuru karne ke liye [MovementDetection.ipynb](../../../../../../lessons/4-ComputerVision/06-IntroCV/lab/MovementDetection.ipynb) kholiye.

## Takeaway

Kabhi-kabhi movement detection ya fingertip detection jaise kaafi complex tasks sirf computer vision se hi solve ho jaate hain. Isliye yeh jaanna bahut kaam ka hai ki OpenCV jaisi libraries kya-kya kar sakti hain.
