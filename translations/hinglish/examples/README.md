## 🚀 Getting Started

### Prerequisites

Make sure aapke paas Python installed hai (3.8 ya usse upar recommended). Required packages install karein:

```bash
# For Python scripts
pip install numpy

# For Jupyter notebooks (image classifier)
pip install jupyter numpy pillow tensorflow
```

Ya main course ka conda environment use karein:

```bash
conda env create --name ai4beg --file ../environment.yml
conda activate ai4beg
```

### Examples chalana

**Python scripts (.py files) ke liye:**
```bash
python 01-hello-ai-world.py
```

**Jupyter notebooks (.ipynb files) ke liye:**
```bash
jupyter notebook 03-image-classifier.ipynb
```

## 📖 Learning Path

Hum suggest karte hain ki aap examples ko is order mein follow karein:

1. **"Hello AI World" se shuru karein** - pattern recognition ke basics seekhein
2. **Ek simple neural network banayein** - samjhein ki neural networks kaise kaam karte hain
3. **Image classifier try karein** - real images ke saath AI ko dekhein
4. **Text sentiment analyze karein** - Natural Language Processing explore karein
