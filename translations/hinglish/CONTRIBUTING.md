# AI-For-Beginners Mein Contribute Karna

AI-For-Beginners mein contribute karne mein interest dikhane ke liye dhanyavaad! Hum translations, lesson corrections, aur formatting fixes ka swagat karte hain.

## Microsoft Contributor License Agreement (CLA)

Yeh project contributions aur suggestions ka swagat karta hai. Zyadatar contributions ke liye aapko ek Contributor License Agreement (CLA) se agree karna padta hai, jisme aap declare karte hain ki aapke paas apne contribution ko use karne ke rights hain aur aap sach mein humein yeh rights de rahe hain. Details ke liye, [https://cla.microsoft.com](https://cla.microsoft.com) par jaiye.

Jab aap pull request submit karte hain, toh ek CLA-bot automatically decide karega ki aapko CLA dene ki zaroorat hai ya nahi aur pull request ko uske hisaab se mark karega (jaise, label, comment). Bas bot ke diye instructions follow kijiye. Aapko yeh sirf ek baar karna hoga un sabhi repositories mein jo hamara CLA use karti hain.

## Contribute Kaise Karein

### 1. Typos / Code Errors Fix Karna
Agar aapko kisi bhi Jupyter notebook ya lesson markdown file mein typos ya bugs milein:
1. Repository ko fork kijiye.
2. Typo ya broken link ko fix kijiye.
3. Fix ka clear description dete hue ek pull request submit kijiye.

### 2. Translations Submit Karna
Hum lessons ke doosri languages mein translations ka swagat karte hain! Kripya translations ko `translations/` directory ke andar maujooda folder names use karte hue rakhiye (jaise `translations/es/`, `translations/pt-BR/`, `translations/zh-CN/`).

Zyada details ke liye, dekhiye [etc/CONTRIBUTING.md](etc/CONTRIBUTING.md).
