## Aap Kya Seekhenge

**[Course ka Mindmap](http://soshnikov.com/courses/ai-for-beginners/mindmap.html)**

Is curriculum mein, aap seekhenge:

* Artificial Intelligence ke alag-alag approaches, jisme "good old" symbolic approach shaamil hai jisme **Knowledge Representation** aur reasoning ([GOFAI](https://en.wikipedia.org/wiki/Symbolic_artificial_intelligence)) aate hain.
* **Neural Networks** aur **Deep Learning**, jo modern AI ke core mein hain. Hum in important topics ke peeche ke concepts ko do sabse popular frameworks - [TensorFlow](http://Tensorflow.org) aur [PyTorch](http://pytorch.org) ke code ka use karke samjhayenge.
* Images aur text ke saath kaam karne ke liye **Neural Architectures**. Hum recent models cover karenge, lekin ho sakta hai ki yeh state-of-the-art mein thoda kamzor ho.
* Kam popular AI approaches, jaise **Genetic Algorithms** aur **Multi-Agent Systems**.

Is curriculum mein hum kya cover nahi karenge:

> [Is course ke saare additional resources hamari Microsoft Learn collection mein paayein](https://learn.microsoft.com/en-us/collections/7w28iy2xrqzdj0?WT.mc_id=academic-77998-bethanycheum)

* Business mein **AI ke business cases**. Microsoft Learn par [Introduction to AI for business users](https://docs.microsoft.com/learn/paths/introduction-ai-for-business-users/?WT.mc_id=academic-77998-bethanycheum) learning path try karein, ya [AI Business School](https://www.microsoft.com/ai/ai-business-school/?WT.mc_id=academic-77998-bethanycheum), jise [INSEAD](https://www.insead.edu/) ke saath collaboration mein develop kiya gaya hai.
* **Classic Machine Learning**, jise hamare [Machine Learning for Beginners Curriculum](http://github.com/Microsoft/ML-for-Beginners) mein achhe se describe kiya gaya hai.
* Practical AI applications jo **[Cognitive Services](https://azure.microsoft.com/services/cognitive-services/?WT.mc_id=academic-77998-bethanycheum)** ka use karke banaye gaye hain. Iske liye, hum Microsoft Learn ke modules recommend karte hain jaise [vision](https://docs.microsoft.com/learn/paths/create-computer-vision-solutions-azure-cognitive-services/?WT.mc_id=academic-77998-bethanycheum), [natural language processing](https://docs.microsoft.com/learn/paths/explore-natural-language-processing/?WT.mc_id=academic-77998-bethanycheum), **[Generative AI with Azure OpenAI Service](https://learn.microsoft.com/en-us/training/paths/develop-ai-solutions-azure-openai/?WT.mc_id=academic-77998-bethanycheum)** aur doosre.
* Specific ML **cloud frameworks**, jaise [Azure Machine Learning](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-bethanycheum), [Microsoft Fabric](https://learn.microsoft.com/en-us/training/paths/get-started-fabric/?WT.mc_id=academic-77998-bethanycheum), ya [Azure Databricks](https://docs.microsoft.com/learn/paths/data-engineer-azure-databricks?WT.mc_id=academic-77998-bethanycheum). Inke liye [Build and operate machine learning solutions with Azure Machine Learning](https://docs.microsoft.com/learn/paths/build-ai-solutions-with-azure-ml-service/?WT.mc_id=academic-77998-bethanycheum) aur [Build and Operate Machine Learning Solutions with Azure Databricks](https://docs.microsoft.com/learn/paths/build-operate-machine-learning-solutions-azure-databricks/?WT.mc_id=academic-77998-bethanycheum) learning paths ka use karne par vichaar karein.
* **Conversational AI** aur **Chat Bots**. Iske liye ek alag [Create conversational AI solutions](https://docs.microsoft.com/learn/paths/create-conversational-ai-solutions/?WT.mc_id=academic-77998-bethanycheum) learning path hai, aur aap zyada details ke liye [is blog post](https://soshnikov.com/azure/hello-bot-conversational-ai-on-microsoft-platform/) ko bhi dekh sakte hain.
* Deep Learning ke peeche ki **deep mathematics**. Iske liye, hum Ian Goodfellow, Yoshua Bengio aur Aaron Courville ki likhi [Deep Learning](https://www.amazon.com/Deep-Learning-Adaptive-Computation-Machine/dp/0262035618) recommend karte hain, jo online [https://www.deeplearningbook.org/](https://www.deeplearningbook.org/) par bhi available hai.

_AI in the Cloud_ topics ka aasaan introduction paane ke liye, aap [Get started with artificial intelligence on Azure](https://docs.microsoft.com/learn/paths/get-started-with-artificial-intelligence-on-azure/?WT.mc_id=academic-77998-bethanycheum) learning path bhi le sakte hain.

### 🎯 AI mein naye hain? Yahan se shuru karein!

Agar aap AI mein bilkul naye hain aur quick, hands-on examples dhoondh rahe hain, toh hamare [**Beginner-Friendly Examples**](./examples/README.md) dekhein! Inmein shaamil hain:  

- 🌟 **Hello AI World** - Aapka pehla AI program (pattern recognition)  
- 🧠 **Simple Neural Network** - Ek neural network ko zero se banayein  
- 🖼️ **Image Classifier** - Detailed comments ke saath images ko classify karein  
- 💬 **Text Sentiment** - Positive/negative text analysis karein  

Yeh examples aapko poore curriculum mein jaane se pehle AI ke concepts samajhne mein madad karne ke liye design kiye gaye hain.
