# របៀបរត់កូដ

កម្មវិធីសិក្សានេះមានឧទាហរណ៍បំពេញនិងមន្ទីរពិសោធន៍ជាច្រើនដែលអ្នកចង់រត់។ ដើម្បីធ្វើដូចនេះ អ្នកត្រូវការជំនាញក្នុងការប្រតិបត្តិកូដ Python នៅក្នុង Jupyter Notebooks ដែលផ្តល់ជូនជាផ្នែកមួយនៃកម្មវិធីសិក្សានេះ។ អ្នកមានជម្រើសជាច្រើនសម្រាប់រត់កូដ៖

## រត់នៅកន្លែងក្នុងកុំព្យូទ័ររបស់អ្នក

ដើម្បីរត់កូដនៅកន្លែងក្នុងកុំព្យូទ័ររបស់អ្នក អ្នកត្រូវការតំឡើង Python។ មួយក្នុងចំណោមការផ្តល់អនុសាសន៍គឺតំឡើង **[miniconda](https://conda.io/en/latest/miniconda.html)** - វាជាការតំឡើងស្រាលដែលគាំទ្រកម្មវិធីគ្រប់គ្រង `conda` សម្រាប់បរិស្ថាន Python **ហ្វីចួល** ផ្សេងៗ។

បន្ទាប់ពីអ្នកតំឡើង miniconda រួច សូមចម្លងរ៉េប៉ូស៊ីតូរីហើយបង្កើតបរិស្ថានហ្វីចួលសម្រាប់ប្រើសម្រាប់វគ្គសិក្សានេះ៖

```bash
git clone http://github.com/microsoft/ai-for-beginners
cd ai-for-beginners
conda env create --name ai4beg --file .devcontainer/environment.yml
conda activate ai4beg
```

> **សម្គាល់ Windows**: ប្រសិនបើការបង្កើតបរិស្ថានបរាជ័យខណៈពេលតំឡើង `gdk-pixbuf` ជាមួយ `UnicodeDecodeError` ដែលចុះសម្គាល់ codec `gbk` សូមបើកមូត UTF-8 របស់ Python នៅក្នុងធឺម៉ីនាលរបស់អ្នក ហើយព្យាយាមម្តងទៀត។ ប្រើសីនថាក់សម្រាប់ធឺម៉ីនាលដែលអ្នកប្រើ៖
>
> **PowerShell:**
>
> ```powershell
> $env:PYTHONUTF8 = "1"
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Command Prompt (`cmd.exe`) ឬ Anaconda Prompt:**
>
> ```cmd
> set PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Bash រួមទាំង Git Bash:**
>
> ```bash
> export PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> ប្រសិនបើព្យាយាមបរាជ័យបានទុកបរិស្ថាន `ai4beg` នៅពីក្រោយ សូមបិទសកម្មភាពវា ហើយលុបបរិស្ថាននោះមុនពេលឆ្លងទៅព្យាយាមម្ដងទៀត។ ប្រើ `conda deactivate` ជាមុនសិននៅពេលបរិស្ថានសកម្ម៖
>
> ```text
> conda deactivate
> conda env remove --name ai4beg
> ```

### ការប្រើប្រាស់ Visual Studio Code ជាមួយបន្ថែម Python

កម្មវិធីសិក្សានេះល្អបំផុតនៅពេលបើកវាក្នុង [Visual Studio Code](http://code.visualstudio.com/?WT.mc_id=academic-77998-cacaste) ជាមួយបន្ថែម [Python Extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python&WT.mc_id=academic-77998-cacaste)។

> **សម្គាល់**: បន្ទាប់ពីអ្នកចម្លងនិងបើកថតឯកសារនៅក្នុង VS Code វានឹងផ្តល់អនុសាសន៍ឱ្យអ្នកតំឡើងបន្ថែម Python ដោយស្វ័យប្រវត្តិ។ អ្នកក៏ត្រូវតំឡើង miniconda ដូចបានពណ៌នាខាងលើផងដែរ។

> **សម្គាល់**: ប្រសិនបើ VS Code ផ្តល់អនុសាសន៍ឱ្យអ្នកបើករ៉េប៉ូស៊ីតូរីម្តងទៀតក្នុងធុង (container) អ្នកគួរបដិសេធដើម្បីប្រើប្រាស់ការតំឡើង Python នៅក្នុងកុំព្យូទ័រជាតេល។

### ការប្រើប្រាស់ Jupyter នៅក្នុងកម្មវិធីរុករក

អ្នកអាចប្រើបរិស្ថាន Jupyter ពីកម្មវិធីរុករកនៅលើកុំព្យូទ័រទាំងអស់របស់អ្នកផ្ទាល់បាន។ ទាំង Jupyter តាមបុរាណនិង JupyterHub ផ្តល់ជូនបរិស្ថានអភិវឌ្ឍន៍មានភាពងាយស្រួល ជាមួយការបញ្ចប់ស្វ័យប្រវត្តិ ការបង្ហាញពណ៌កូដ និងផ្សេងៗទៀត។

ដើម្បីចាប់ផ្តើម Jupyter នៅកន្លែងក្នុងកុំព្យូទ័រ សូមទៅកាន់ថតវគ្គសិក្សា ហើយបញ្ចូលពាក្យបញ្ជា៖

```bash
jupyter notebook
```
or
```bash
jupyterhub
```
 អ្នកទើបអាចរុករកឯកសារ `.ipynb` ណាមួយ បើកវានិងចាប់ផ្តើមធ្វើការងារ។

### រត់នៅក្នុងធុង (container)

មួយជម្រើសជំនួសសម្រាប់ការតំឡើង Python គឺរត់កូដនៅក្នុងធុង។ ព្រោះរ៉េប៉ូស៊ីតូរីរបស់យើងផ្គត់ផ្គង់ថត `.devcontainer` ពិសេសដែលបង្ហាញពីរបៀបកសាងធុងសម្រាប់រ៉េប៉ូនេះ ពហុភាព វីអេសកូដផ្តល់ឱកាសឱ្យបើកកូដឡើងវិញនៅក្នុងធុង។ នេះតម្រូវឲ្យតំឡើង Docker ហើយវានឹងស្មុគស្មាញជាងនេះទៀត ដូច្នេះយើងផ្ដល់អនុសាសន៍សម្រាប់អ្នកប្រើប្រាស់ដែលមានបទពិសោធន៍ជាង។

## រត់នៅលើពពក (Cloud)

ប្រសិនបើអ្នកមិនចង់តំឡើង Python នៅក្នុងកុំព្យូទ័រផ្ទាល់ខ្លួនទេ ហើយមានការចូលដំណើរការទៅកាន់ធនធានពពកខ្លះៗ - ជម្រើសល្អគឺរត់កូដនៅលើពពក។ មានវិធីជាច្រើនដែលអ្នកអាចធ្វើបាន៖

* ការប្រើប្រាស់ **[GitHub Codespaces](https://github.com/features/codespaces)** ដែលជាបរិក្ខារជាក់វេជ្ជសាស្ត្រដែលបានបង្កើតសម្រាប់អ្នកនៅលើ GitHub អាចចូលដំណើរការយ៉ាងងាយស្រួលតាមរយៈផ្ទាំងអ្នកស្វែងរក VS Code ។ ប្រសិនបើអ្នកមានការចូលដំណើរការទៅកាន់ Codespaces អ្នកអាចចុចប៊ូតុង **Code** នៅក្នុងរូបិច្ឆេទ ហើយចាប់ផ្តើមកូដស្ពេស ហើយចាប់ផ្តើមប្រតិបត្តិការ យ៉ាងឆាប់រហ័ស។
* ការប្រើប្រាស់ **[Binder](https://mybinder.org/v2/gh/microsoft/ai-for-beginners/HEAD)**។ [Binder](https://mybinder.org) ផ្ដល់ឱ្យនូវធនធានកុំព្យូទ័រឥតគិតថ្លៃដែលផ្ដល់នៅក្នុងពពកសម្រាប់មនុស្សដូចអ្នក ដើម្បីសាកល្បងកូដមួយចំនួននៅលើ GitHub។ មានប៊ូតុងនៅលើទំព័រដើមដើម្បីបើកផ្ទាំងរក្សារនៅក្នុង Binder - នេះគួរតែបញ្ជូនអ្នកទៅគេហទំព័រ binder យ៉ាងឆាប់រហ័ស ដែលនឹងសាងសង់កంటឺន័រមួយនៅពីក្រោយ និងចាប់ផ្តើមផ្ទាំងបណ្ដាញ Jupyter សម្រាប់អ្នកដោយឥតខ្ចោះ។

> **កំណត់ចិត្ត**៖ ដើម្បីទប់ស្កាត់ការប្រើប្រាស់ខុស ប្រព័ន្ធ Binder មានការចូលដំណើរការទៅកាន់ធនធានបណ្តាញខ្លះៗត្រូវបានរារាំង។ នេះអាចបញ្ឈប់មិនឲ្យកូដខ្លះដំណើរការ ដែលទាញយកគំរូ និង/ឬសំណុំទិន្នន័យពីអ៊ីនធឺណិតសាធារណៈ។ អ្នកប្រហែលជាត្រូវបានទាមទារទៅរកវិធីដោះស្រាយផ្សេងៗ។ លើសពីនេះធនធានគណនា ដែលបញ្ជូនដោយ Binder គឺមូលដ្ឋានខ្លះៗ ដូច្នេះការបណ្តុះបណ្តាលនឹងយឺត ជាពិសេសនៅវគ្គក្រោយ ដែលស្មុគស្មាញជាង។

## ប្រតិបត្តិការ​នៅក្នុងពពក​ជាមួយ GPU

វគ្គក្រោយៗខ្លះក្នុងមុខវិជ្ជានេះ នឹងទទួលបានអត្ថប្រយោជន៍យ៉ាងខ្លាំងពីការគាំទ្រ GPU។ ការបណ្តុះបណ្តាលគំរូ គឺអាចយឺតខ្លាំងដោយមិនមានGPU។ មានជម្រើសមួយចំនួនដែលអ្នកអាចអនុវត្ត ដោយឡែកប្រសិនបើអ្នកមានការចូលដំណើរការទៅកាន់ពពក តាមរយៈ [Azure for Students](https://azure.microsoft.com/free/students/?WT.mc_id=academic-77998-cacaste) ឬតាមរយៈស្ថាប័នរបស់អ្នក៖

* បង្កើត [Data Science Virtual Machine](https://docs.microsoft.com/learn/modules/intro-to-azure-data-science-virtual-machine/?WT.mc_id=academic-77998-cacaste) ហើយភ្ជាប់ទៅវាតាមរយៈ Jupyter ។ អ្នកអាចចម្លង repository ទៅកាន់ម៉ាស៊ីននេះ ហើយចាប់ផ្តើមរៀនដោយផ្ទាល់។ ម៉ាស៊ីន NC-series មានការគាំទ្រ GPU។

> **កំណត់ចិត្ត**៖ សេវាកម្មជាច្រើន រួមទាំង Azure for Students មិនផ្ដល់ការគាំទ្រ GPU ដូចជាមុនទេ។ អ្នកប្រហែលជាត្រូវដាក់ស្នើសំណើសុំ additional GPU cores ជាមួយសំណើបច្ចេកទេស។

* បង្កើត [Azure Machine Learning Workspace](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-cacaste) ហើយបន្ទាប់មកប្រើលក្ខណៈ Notebook នៅទីនោះ។ [វីដេអូនេះ](https://azure-for-academics.github.io/quickstart/azureml-papers/) បង្ហាញពីវិធីចម្លង repository ទៅក្នុង Azure ML notebook ហើយចាប់ផ្តើមប្រើវា។

អ្នកក៏អាចប្រើ Google Colab ដែលមានការគាំទ្រ GPU ។ ហើយផ្ទុកឯកសារ Jupyter Notebook ទៅទីនោះដើម្បីអនុវត្តិវាដោយខ្លួនឯងមួយៗ។
