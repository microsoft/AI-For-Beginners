# Як запускати код

Ця навчальна програма містить багато виконуваних прикладів та лабораторних робіт, які ви захочете запускати. Для цього вам потрібна можливість виконувати код Python у Jupyter Notebook, що надаються в рамках цієї програми. У вас є кілька варіантів для запуску коду:

## Запуск локально на вашому комп’ютері

Для запуску коду локально на вашому комп’ютері потрібно встановити Python. Однією з рекомендацій є встановлення **[miniconda](https://conda.io/en/latest/miniconda.html)** — це досить легка установка, яка підтримує менеджер пакетів `conda` для створення різних **віртуальних середовищ** Python.

Після встановлення miniconda клонувати репозиторій та створити віртуальне середовище, яке використовуватиметься для цього курсу:

```bash
git clone http://github.com/microsoft/ai-for-beginners
cd ai-for-beginners
conda env create --name ai4beg --file .devcontainer/environment.yml
conda activate ai4beg
```

> **Примітка для Windows**: Якщо створення середовища не вдається під час встановлення `gdk-pixbuf` із `UnicodeDecodeError`, який згадує `gbk` кодек, увімкніть режим UTF-8 Python у вашому терміналі та спробуйте ще раз. Використовуйте синтаксис для вашого терміналу:
>
> **PowerShell:**
>
> ```powershell
> $env:PYTHONUTF8 = "1"
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Командний рядок (`cmd.exe`) або Anaconda Prompt:**
>
> ```cmd
> set PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Bash, зокрема Git Bash:**
>
> ```bash
> export PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> Якщо невдала спроба залишила середовище `ai4beg`, деактивуйте його та видаліть перед повторною спробою. Використовуйте `conda deactivate` спочатку, коли середовище активне:
>
> ```text
> conda deactivate
> conda env remove --name ai4beg
> ```

### Використання Visual Studio Code з розширенням Python

Цю навчальну програму найкраще використовувати, відкриваючи її у [Visual Studio Code](http://code.visualstudio.com/?WT.mc_id=academic-77998-cacaste) з [розширенням Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python&WT.mc_id=academic-77998-cacaste).

> **Примітка**: Після клонування і відкриття каталогу у VS Code він автоматично запропонує встановити розширення Python. Вам також доведеться встановити miniconda, як описано вище.

> **Примітка**: Якщо VS Code запропонує відкрити репозиторій у контейнері, варто відмовитись, щоб використовувати локальну установку Python.

### Використання Jupyter у браузері

Ви також можете використовувати Jupyter-середовище з браузера на власному комп’ютері. Як класичний Jupyter, так і JupyterHub надають зручне середовище розробки з автодоповненням, підсвіткою коду тощо.

Щоб запустити Jupyter локально, перейдіть у каталог курсу та виконайте:

```bash
jupyter notebook
```
або
```bash
jupyterhub
```
Потім ви можете перейти до будь-якого з файлів `.ipynb`, відкрити їх і почати роботу.

### Запуск у контейнері

Однією з альтернатив встановленню Python є запуск коду у контейнері. Оскільки наш репозиторій містить спеціальну папку `.devcontainer`, яка описує, як збирати контейнер для цього репозиторію, VS Code пропонує можливість знову відкрити код у контейнері. Це потребує встановлення Docker і є більш складним, тому ми рекомендуємо це досвідченим користувачам.

## Запуск у хмарі

Якщо ви не хочете встановлювати Python локально та маєте доступ до деяких хмарних ресурсів, хорошою альтернативою буде запуск коду в хмарі. Існує кілька способів зробити це:

* Використання **[GitHub Codespaces](https://github.com/features/codespaces)** — віртуального середовища, створеного для вас на GitHub, доступного через інтерфейс VS Code у браузері. Якщо у вас є доступ до Codespaces, ви просто натискаєте кнопку **Code** у репозиторії, запускаєте Codespace і дуже швидко починаєте працювати.
* Використання **[Binder](https://mybinder.org/v2/gh/microsoft/ai-for-beginners/HEAD)**. [Binder](https://mybinder.org) надає безкоштовні обчислювальні ресурси в хмарі для людей, як ви, щоб тестувати код з GitHub. На головній сторінці є кнопка для відкриття репозиторію в Binder — це швидко перенаправить вас на сайт binder, який збере підґрунтяну контейнерну інфраструктуру та запустить веб-інтерфейс Jupyter.

> **Примітка**: Щоб запобігти зловживанню, у Binder заблоковано доступ до деяких веб-ресурсів. Це може унеможливити роботу коду, який завантажує моделі і/або датасети з публічного інтернету. Вам можуть знадобитися обхідні шляхи. Також обчислювальні ресурси від Binder досить базові, тому навчання буде повільним, особливо на пізніших, більш складних уроках.

## Запуск у хмарі з GPU

Деякі пізніші уроки в цій навчальній програмі значно виграють від підтримки GPU. Наприклад, тренування моделей без цього може бути надзвичайно повільним. Є кілька варіантів, особливо якщо у вас є доступ до хмари через [Azure for Students](https://azure.microsoft.com/free/students/?WT.mc_id=academic-77998-cacaste) або через вашу установу:

* Створити [Data Science Virtual Machine](https://docs.microsoft.com/learn/modules/intro-to-azure-data-science-virtual-machine/?WT.mc_id=academic-77998-cacaste) та підключитися до неї через Jupyter. Потім можна клонувати репозиторій безпосередньо на машину та почати навчання. Віртуальні машини серії NC підтримують GPU.

> **Примітка**: Деякі підписки, зокрема Azure for Students, не надають GPU підтримки за замовчуванням. Вам може знадобитися подати технічний запит на додаткові GPU ядра.

* Створити [Azure Machine Learning Workspace](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-cacaste) та використовувати там функцію Notebook. [Це відео](https://azure-for-academics.github.io/quickstart/azureml-papers/) показує, як клонувати репозиторій у Azure ML notebook та почати його використовувати.

Ви також можете використовувати Google Colab, який пропонує певну безкоштовну GPU підтримку, і завантажувати туди Jupyter Notebook для послідовного виконання.
