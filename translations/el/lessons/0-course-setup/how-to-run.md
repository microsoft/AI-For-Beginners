# Πώς να Εκτελέσετε τον Κώδικα

Αυτό το πρόγραμμα σπουδών περιλαμβάνει πολλά εκτελέσιμα παραδείγματα και εργαστήρια που θα θέλατε να εκτελέσετε. Για να το κάνετε αυτό, χρειάζεστε τη δυνατότητα εκτέλεσης κώδικα Python σε Jupyter Notebooks που παρέχονται ως μέρος αυτού του προγράμματος σπουδών. Έχετε αρκετές επιλογές για να τρέξετε τον κώδικα:

## Εκτέλεση τοπικά στον υπολογιστή σας

Για να εκτελέσετε τον κώδικα τοπικά στον υπολογιστή σας, χρειάζεται μια εγκατάσταση Python. Μια σύσταση είναι να εγκαταστήσετε **[miniconda](https://conda.io/en/latest/miniconda.html)** - είναι μια ελαφριά εγκατάσταση που υποστηρίζει τον διαχειριστή πακέτων `conda` για διάφορα **εικονικά περιβάλλοντα** Python.

Αφού εγκαταστήσετε το miniconda, κλωνοποιήστε το αποθετήριο και δημιουργήστε ένα εικονικό περιβάλλον για χρήση σε αυτό το μάθημα:

```bash
git clone http://github.com/microsoft/ai-for-beginners
cd ai-for-beginners
conda env create --name ai4beg --file .devcontainer/environment.yml
conda activate ai4beg
```

> **Σημείωση για Windows**: Αν η δημιουργία περιβάλλοντος αποτύχει κατά την εγκατάσταση του `gdk-pixbuf` με ένα `UnicodeDecodeError` που αναφέρει τον κωδικοποιητή `gbk`, ενεργοποιήστε τη λειτουργία UTF-8 της Python στο τερματικό σας και δοκιμάστε ξανά. Χρησιμοποιήστε τη σύνταξη για το τερματικό που χρησιμοποιείτε:
>
> **PowerShell:**
>
> ```powershell
> $env:PYTHONUTF8 = "1"
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Γραμμή εντολών (`cmd.exe`) ή Anaconda Prompt:**
>
> ```cmd
> set PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Bash, συμπεριλαμβανομένου του Git Bash:**
>
> ```bash
> export PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> Αν μια αποτυχημένη προσπάθεια άφησε πίσω της το περιβάλλον `ai4beg`, απενεργοποιήστε το και αφαιρέστε το περιβάλλον προτού δοκιμάσετε ξανά. Χρησιμοποιήστε `conda deactivate` πρώτα όταν ένα περιβάλλον είναι ενεργό:
>
> ```text
> conda deactivate
> conda env remove --name ai4beg
> ```

### Χρήση του Visual Studio Code με το Python Extension

Αυτό το πρόγραμμα σπουδών χρησιμοποιείται καλύτερα όταν το ανοίγετε στο [Visual Studio Code](http://code.visualstudio.com/?WT.mc_id=academic-77998-cacaste) με το [Python Extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python&WT.mc_id=academic-77998-cacaste).

> **Σημείωση**: Μόλις κλωνοποιήσετε και ανοίξετε το φάκελο στο VS Code, θα σας προταθεί αυτόματα να εγκαταστήσετε επεκτάσεις Python. Επίσης θα χρειαστεί να εγκαταστήσετε miniconda όπως περιγράφεται παραπάνω.

> **Σημείωση**: Αν το VS Code σας προτείνει να ξανανοίξετε το αποθετήριο σε ένα container, καλό είναι να αρνηθείτε αυτή την επιλογή για να χρησιμοποιήσετε την τοπική εγκατάσταση Python.

### Χρήση του Jupyter στον Περιηγητή

Μπορείτε επίσης να χρησιμοποιήσετε ένα περιβάλλον Jupyter από τον περιηγητή στον δικό σας υπολογιστή. Τόσο το κλασικό Jupyter όσο και το JupyterHub παρέχουν ένα βολικό περιβάλλον ανάπτυξης με αυτόματη συμπλήρωση, επισημάνσεις κώδικα κτλ.

Για να ξεκινήσετε το Jupyter τοπικά, πηγαίνετε στον φάκελο του μαθήματος και εκτελέστε:

```bash
jupyter notebook
```
ή
```bash
jupyterhub
```
Στη συνέχεια μπορείτε να περιηγηθείτε σε οποιοδήποτε από τα αρχεία `.ipynb`, να τα ανοίξετε και να ξεκινήσετε να εργάζεστε.

### Εκτέλεση σε container

Μια εναλλακτική στην εγκατάσταση της Python είναι να τρέξετε τον κώδικα μέσα σε ένα container. Εφόσον το αποθετήριο μας παρέχει έναν ειδικό φάκελο `.devcontainer` που δίνει οδηγίες για το πώς να φτιάξετε ένα container για αυτό το repo, το VS Code προσφέρει τη δυνατότητα να ξανανοίξετε τον κώδικα μέσα σε container. Αυτό θα απαιτήσει εγκατάσταση Docker, και θα είναι πιο σύνθετο, οπότε το προτείνουμε σε πιο έμπειρους χρήστες.

## Εκτέλεση στο Cloud

Αν δεν θέλετε να εγκαταστήσετε την Python τοπικά και έχετε πρόσβαση σε κάποιους πόρους cloud - καλή εναλλακτική είναι να τρέξετε τον κώδικα στο cloud. Υπάρχουν διάφοροι τρόποι να το κάνετε:

* Χρήση του **[GitHub Codespaces](https://github.com/features/codespaces)**, που είναι ένα εικονικό περιβάλλον δημιουργημένο για εσάς στο GitHub, προσβάσιμο μέσω ενός περιβάλλοντος περιηγητή VS Code. Αν έχετε πρόσβαση σε Codespaces, απλά κάντε κλικ στο κουμπί **Code** στο repo, ξεκινήστε έναν codespace, και αρχίστε να εργάζεστε αμέσως.
* Χρήση του **[Binder](https://mybinder.org/v2/gh/microsoft/ai-for-beginners/HEAD)**. Το [Binder](https://mybinder.org) προσφέρει δωρεάν υπολογιστικούς πόρους μέσω cloud για ανθρώπους σαν εσάς να δοκιμάσουν κώδικα από το GitHub. Υπάρχει ένας κουμπί στην αρχική σελίδα για να ανοίξετε το αποθετήριο στο Binder - αυτό θα σας μεταφέρει γρήγορα στην ιστοσελίδα του binder, που θα χτίσει το υποστηρικτικό container και θα ξεκινήσει ένα web interface Jupyter για εσάς χωρίς διακοπή.

> **Σημείωση**: Για την αποφυγή κακόχρησης, το Binder έχει μπλοκαρισμένη την πρόσβαση σε κάποιους διαδικτυακούς πόρους. Αυτό μπορεί να εμποδίσει κάποιον κώδικα που ανακτά μοντέλα και/ή σύνολα δεδομένων από το δημόσιο Διαδίκτυο να λειτουργήσει. Μπορεί να χρειαστεί να βρείτε κάποιους τρόπους παράκαμψης. Επίσης, οι πόροι υπολογισμού που παρέχει το Binder είναι αρκετά βασικοί, οπότε η εκπαίδευση θα είναι αργή, ειδικά σε μεταγενέστερα, πιο σύνθετα μαθήματα.

## Εκτέλεση στο Cloud με GPU

Μερικά από τα μεταγενέστερα μαθήματα σε αυτό το πρόγραμμα σπουδών θα επωφεληθούν σημαντικά από την υποστήριξη GPU. Η εκπαίδευση μοντέλων, για παράδειγμα, μπορεί να είναι επώδυνα αργή διαφορετικά. Υπάρχουν μερικές επιλογές που μπορείτε να ακολουθήσετε, ειδικά αν έχετε πρόσβαση στο cloud είτε μέσω του [Azure for Students](https://azure.microsoft.com/free/students/?WT.mc_id=academic-77998-cacaste), είτε μέσω του ιδρύματός σας:

* Δημιουργήστε [Data Science Virtual Machine](https://docs.microsoft.com/learn/modules/intro-to-azure-data-science-virtual-machine/?WT.mc_id=academic-77998-cacaste) και συνδεθείτε σε αυτή μέσω Jupyter. Μπορείτε τότε να κλωνοποιήσετε το repo κατευθείαν στη μηχανή και να ξεκινήσετε τη μάθηση. Οι NC-series VM υποστηρίζουν GPU.

> **Σημείωση**: Κάποιες συνδρομές, συμπεριλαμβανομένου του Azure for Students, δεν παρέχουν αυτόματη υποστήριξη GPU. Μπορεί να χρειαστεί να ζητήσετε επιπλέον πυρήνες GPU με ένα αίτημα τεχνικής υποστήριξης.

* Δημιουργήστε [Azure Machine Learning Workspace](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-cacaste) και χρησιμοποίηστε το χαρακτηριστικό Notebook εκεί. [Αυτό το βίντεο](https://azure-for-academics.github.io/quickstart/azureml-papers/) δείχνει πώς να κλωνοποιήσετε ένα αποθετήριο σε ένα Azure ML notebook και να το αρχίσετε να το χρησιμοποιείτε.

Μπορείτε επίσης να χρησιμοποιήσετε το Google Colab, που προσφέρει κάποια δωρεάν υποστήριξη GPU, και να ανεβάσετε εκεί Jupyter Notebooks για να εκτελέσετε το ένα μετά το άλλο.
