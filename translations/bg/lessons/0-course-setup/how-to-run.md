# Как да стартирате кода

Тази учебна програма съдържа много изпълними примери и лабораторни упражнения, които бихте искали да стартирате. За да направите това, ви е необходима възможност за изпълнение на Python код в Jupyter Notebooks, предоставени като част от тази учебна програма. Имате няколко опции за стартиране на кода:

## Стартиране локално на вашия компютър

За да стартирате кода локално на вашия компютър, е необходима инсталация на Python. Една препоръка е да инсталирате **[miniconda](https://conda.io/en/latest/miniconda.html)** - това е сравнително лека инсталация, която поддържа `conda` пакетния мениджър за различни Python **виртуални среди**.

След като инсталирате miniconda, клонирайте хранилището и създайте виртуална среда, която да използвате за този курс:

```bash
git clone http://github.com/microsoft/ai-for-beginners
cd ai-for-beginners
conda env create --name ai4beg --file .devcontainer/environment.yml
conda activate ai4beg
```

> **Забележка за Windows**: Ако създаването на средата се провали при инсталиране на `gdk-pixbuf` с `UnicodeDecodeError`, който споменава `gbk` кодека, активирайте UTF-8 режима на Python в терминала си и опитайте отново. Използвайте синтаксиса за терминала, който използвате:
>
> **PowerShell:**
>
> ```powershell
> $env:PYTHONUTF8 = "1"
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Command Prompt (`cmd.exe`) или Anaconda Prompt:**
>
> ```cmd
> set PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> **Bash, включително Git Bash:**
>
> ```bash
> export PYTHONUTF8=1
> conda env create --name ai4beg --file .devcontainer/environment.yml
> ```
>
> Ако неуспешен опит е оставил `ai4beg` среда, деактивирайте я и я премахнете преди да пробвате отново. Използвайте `conda deactivate` първо, когато средата е активна:
>
> ```text
> conda deactivate
> conda env remove --name ai4beg
> ```

### Използване на Visual Studio Code с Python разширение

Тази учебна програма е най-добре използвана, когато се отваря в [Visual Studio Code](http://code.visualstudio.com/?WT.mc_id=academic-77998-cacaste) с [Python Extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python&WT.mc_id=academic-77998-cacaste).

> **Забележка**: След като клонирате и отворите директорията във VS Code, то автоматично ще ви предложи да инсталирате Python разширенията. Ще трябва също да инсталирате miniconda, както е описано по-горе.

> **Забележка**: Ако VS Code ви предложи да отворите хранилището в контейнер, трябва да откажете това, за да използвате локалната Python инсталация.

### Използване на Jupyter в браузър

Можете също да използвате Jupyter среда от браузъра на вашия компютър. Класическият Jupyter и JupyterHub предоставят удобна среда за разработка с авто-попълване, оцветяване на код и др.

За да стартирате Jupyter локално, отидете в директорията на курса и изпълнете:

```bash
jupyter notebook
```
или
```bash
jupyterhub
```
След това можете да навигирате до който и да е `.ipynb` файл, да го отворите и да започнете работа.

### Стартиране в контейнер

Една алтернатива на инсталацията на Python е да стартирате кода в контейнер. Тъй като нашето хранилище предоставя специална `.devcontainer` папка, която указва как да се изгради контейнер за това хранилище, VS Code предлага възможност да отворите кода в контейнер. Това изисква инсталация на Docker и е по-сложно, така че го препоръчваме на по-опитни потребители.

## Стартиране в облака

Ако не искате да инсталирате Python локално и имате достъп до облачни ресурси, добра алтернатива е да стартирате кода в облака. Има няколко начина да го направите:

* Използване на **[GitHub Codespaces](https://github.com/features/codespaces)**, която е виртуална среда създадена за вас в GitHub, достъпна през VS Code браузърен интерфейс. Ако имате достъп до Codespaces, просто кликнете върху бутона **Code** в хранилището, стартирайте codespace и започнете веднага.
* Използване на **[Binder](https://mybinder.org/v2/gh/microsoft/ai-for-beginners/HEAD)**. [Binder](https://mybinder.org) предлага безплатни изчислителни ресурси, предоставени в облака, за хора като вас, за да тествате код от GitHub. На началната страница има бутон за отваряне на хранилището в Binder – това бързо ще ви отведе до сайта на Binder, който ще изгради основния контейнер и плавно ще стартира Jupyter уеб интерфейс за вас.

> **Забележка**: За да се предотврати злоупотреба, Binder блокира достъпа до някои уеб ресурси. Това може да попречи на част от кода, който изтегля модели и/или набори от данни от публичния Интернет, да работи. Може да се наложи да намерите някакви заобиколни решения. Също така изчислителните ресурси, предоставяни от Binder, са доста базови, така че обучението ще е бавно, особено в по-късните, по-сложни уроци.

## Стартиране в облака с GPU

Някои от по-късните уроци в тази учебна програма ще се възползват значително от поддръжка на GPU. Обучението на модели, например, може в противен случай да е болезнено бавно. Има няколко опции, които можете да последвате, особено ако имате достъп до облак чрез [Azure for Students](https://azure.microsoft.com/free/students/?WT.mc_id=academic-77998-cacaste) или чрез вашата институция:

* Създайте [Data Science Virtual Machine](https://docs.microsoft.com/learn/modules/intro-to-azure-data-science-virtual-machine/?WT.mc_id=academic-77998-cacaste) и се свържете с нея чрез Jupyter. Можете след това директно да клонирате хранилището на машината и да започнете да учите. NC-серия VMs имат поддръжка на GPU.

> **Забележка**: Някои абонаменти, включително Azure for Students, не предоставят GPU поддръжка по подразбиране. Може да се наложи да поискате допълнителни GPU ядра чрез заявка за техническа поддръжка.

* Създайте [Azure Machine Learning Workspace](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-cacaste) и след това използвайте функцията Notebook там. [Това видео](https://azure-for-academics.github.io/quickstart/azureml-papers/) показва как да клонирате хранилище в Azure ML notebook и да започнете да го използвате.

Можете също да използвате Google Colab, което предлага безплатна GPU поддръжка и да качвате Jupyter Notebooks там, за да ги изпълнявате един по един.
