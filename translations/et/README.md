## Mida sa õpid

**[Kursuse mõttekaart](http://soshnikov.com/courses/ai-for-beginners/mindmap.html)**

Selles õppekavas õpid:

* Erinevaid lähenemisi tehisintellektile, sh "head vana" sümboolset lähenemist koos **teadmiste esindamise** ja järeldamisega ([GOFAI](https://en.wikipedia.org/wiki/Symbolic_artificial_intelligence)).
* **Närvivõrgud** ja **sügav õppimine**, mis on moodsa tehisintellekti aluseks. Tutvustame nende oluliste teemade kontseptsioone kahe populaarse raamistiku – [TensorFlow](http://Tensorflow.org) ja [PyTorch](http://pytorch.org) – koodi kaudu.
* **Närvistaarhitektuurid** piltide ja tekstiga töötamiseks. Käsitleme hiljutisi mudeleid, kuid võib-olla ei kata kõige uuemaid saavutusi.
* Vähem levinud TI-lähenemisi, nagu **geneetilised algoritmid** ja **mitmeagendisüsteemid**.

Mida me selles õppekavas ei käsitle:

> [Leia kõik täiendavad ressursid selle kursuse jaoks Microsoft Learn kogumikus](https://learn.microsoft.com/en-us/collections/7w28iy2xrqzdj0?WT.mc_id=academic-77998-bethanycheum)

* **Klassikaline masinõpe**, mida on põhjalikult kirjeldatud meie [Masinõppe algajate õppekavas](http://github.com/Microsoft/ML-for-Beginners).
* Praktilised TI rakendused, mis on ehitatud kasutades **[Cognitive Services](https://azure.microsoft.com/services/cognitive-services/?WT.mc_id=academic-77998-bethanycheum)** teenuseid. Selleks soovitame alustada Microsoft Learni moodulitest [nägemine](https://docs.microsoft.com/learn/paths/create-computer-vision-solutions-azure-cognitive-services/?WT.mc_id=academic-77998-bethanycheum), [loomuliku keele töötlus](https://docs.microsoft.com/learn/paths/explore-natural-language-processing/?WT.mc_id=academic-77998-bethanycheum), **[Generatiivne TI Azure OpenAI teenusega](https://learn.microsoft.com/en-us/training/paths/develop-ai-solutions-azure-openai/?WT.mc_id=academic-77998-bethanycheum)** ja teised.
* Spetsiifilised ML **pilveraamistikud**, nagu [Azure Machine Learning](https://azure.microsoft.com/services/machine-learning/?WT.mc_id=academic-77998-bethanycheum), [Microsoft Fabric](https://learn.microsoft.com/en-us/training/paths/get-started-fabric/?WT.mc_id=academic-77998-bethanycheum) või [Azure Databricks](https://docs.microsoft.com/learn/paths/data-engineer-azure-databricks?WT.mc_id=academic-77998-bethanycheum). Soovitame kasutada õpiteid [Loo ja halda masinõppe lahendusi Azure Machine Learninguga](https://docs.microsoft.com/learn/paths/build-ai-solutions-with-azure-ml-service/?WT.mc_id=academic-77998-bethanycheum) ja [Loo ja halda masinõppe lahendusi Azure Databricksiga](https://docs.microsoft.com/learn/paths/build-operate-machine-learning-solutions-azure-databricks/?WT.mc_id=academic-77998-bethanycheum).
* **Kõnelejatest AI** ja **vestlusbotid**. Selle jaoks on eraldi õpitee [Loo kõnelejalt AI lahendusi](https://docs.microsoft.com/learn/paths/create-conversational-ai-solutions/?WT.mc_id=academic-77998-bethanycheum) ning võid lisaks tutvuda [selle blogipostitusega](https://soshnikov.com/azure/hello-bot-conversational-ai-on-microsoft-platform/).
* **Sügav matemaatika** süvaõppe taga. Selle jaoks soovitame [Deep Learning](https://www.amazon.com/Deep-Learning-Adaptive-Computation-Machine/dp/0262035618) autoritelt Ian Goodfellow, Yoshua Bengio ja Aaron Courville, mis on saadaval ka veebis aadressil [https://www.deeplearningbook.org/](https://www.deeplearningbook.org/).
